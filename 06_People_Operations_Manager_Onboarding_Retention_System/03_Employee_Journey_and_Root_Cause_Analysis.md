# Employee Journey & Root-Cause Analysis

## Current Journey
Offer accepted → preboarding → Day 1 → first week → role training → manager coaching → 30-day check-in → 60-day development → 90-day readiness/retention review.

## Failure Points
Late access/equipment; incomplete payroll/HR setup; manager not prepared; unclear first-week agenda; inconsistent training; check-ins missed; employee feedback collected too late; risks managed reactively.

## Root-Cause Themes
Ownership ambiguity, fragmented handoffs, inconsistent manager execution, weak milestone standards, limited data visibility, and no integrated early-risk review.

## Priority
P1 Day-1 readiness; P2 manager accountability; P3 role readiness/training; P4 employee listening and retention-risk intervention.
