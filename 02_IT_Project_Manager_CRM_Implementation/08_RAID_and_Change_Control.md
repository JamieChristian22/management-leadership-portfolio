# RAID & Change Control Framework

## RAID
Risks, assumptions, issues, and dependencies are reviewed weekly with owner, impact, response, due date, and escalation status.

## Change Request Flow
Submit → impact assessment → recommendation → sponsor/business approval → baseline update → communicate → implement → validate.

## Impact Dimensions
Scope, timeline, cost/effort, data, security/access, testing, training, integration, operational readiness, and benefits.

## Decision Principle
Protect go-live stability and business value. Nice-to-have changes that threaten critical-path readiness are deferred unless sponsor-approved.
