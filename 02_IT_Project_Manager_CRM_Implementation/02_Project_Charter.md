# Project Charter

## Project
CRM Implementation for Sales Pipeline Visibility

## Sponsor
Director of Operations

## Project Manager
IT Project Manager

## Business Need
Create one governed system of record for customer, lead, opportunity, renewal, and activity data while reducing manual tracking and improving leadership visibility.

## Scope
### In Scope
Requirements, workflow design, data mapping/cleansing, CRM configuration, role/access design, integration validation, UAT, training, cutover, hypercare, KPI reporting, governance, and handoff.

### Out of Scope
Enterprise ERP replacement, major custom application development, new headcount, historical data older than the approved migration window, and unrelated sales-process redesign.

## Success Criteria
- Active-user adoption >= 90%
- Migration accuracy >= 98%
- Duplicate rate <= 3%
- UAT pass rate >= 95%
- Training completion >= 95%
- Critical Sev-1 defects at go-live = 0
- Pipeline report refresh = Daily

## Timeline
10-week implementation plus 30-day hypercare.

## Governance
Weekly project working session; weekly RAID review; biweekly sponsor steering update; formal go/no-go review; daily hypercare triage during Week 1 post-launch.

## Approval Gates
Requirements sign-off, data readiness, UAT exit, training readiness, cutover readiness, go/no-go, and hypercare exit.
