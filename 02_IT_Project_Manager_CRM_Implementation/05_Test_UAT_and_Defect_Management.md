# Test, UAT & Defect Management

## Test Layers
Configuration testing, integration testing, migration validation, role/access testing, reporting validation, regression testing, and business UAT.

## UAT Exit Criteria
>=95% test cases passed; 100% critical business processes tested; zero open Sev-1 defects; Sev-2 defects have approved workaround/owner/date; business owner signs off.

## Defect Severity
Sev-1: production/go-live blocker. Sev-2: major function impaired. Sev-3: moderate issue/workaround exists. Sev-4: cosmetic/minor.

## Defect Workflow
Log → triage → assign → remediate → retest → close/defer with approval.

## Daily UAT Readout
Tests executed, pass rate, defects opened/closed, blockers, owner, ETA, and go-live impact.
