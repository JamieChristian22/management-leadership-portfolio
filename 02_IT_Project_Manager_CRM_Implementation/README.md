# IT Project Management — CRM Implementation

A corporate-style simulated CRM implementation work package covering the full project lifecycle from business case and requirements through migration, testing, cutover, adoption, hypercare, governance, and benefits realization.

## Work Products
- Executive brief and project charter
- Requirements and future-state process design
- Data migration and reconciliation plan
- Test/UAT and defect management
- Cutover, go/no-go, rollback, and hypercare plan
- Change management and training
- RAID and change control
- Steering committee readout
- Support operating model and handoff
- Benefits realization / post-implementation review
- Data dictionary and decision log
- Formula-driven Excel PMO operating workbook
- Weekly modeled source data

## Scenario Targets
4,800 active records; >=90% adoption; >=98% migration accuracy; <=3% duplicate rate; >=95% UAT pass; >=95% training completion; zero Sev-1 defects at go-live; daily pipeline reporting.

## Credibility Note
This is a simulated/modelled project created to demonstrate IT project-management work products and decision-making. It does not represent employer performance or a production CRM deployment.
