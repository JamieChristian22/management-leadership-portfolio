# Support Operating Model & Handoff

## Tiered Support
Tier 1: user guidance, access basics, known issues. Tier 2: CRM admin/configuration and data-quality issues. Tier 3: vendor/integration engineering.

## Service Controls
Severity classification, response targets, ticket ownership, escalation path, known-error documentation, and weekly trend review.

## Handoff Package
System ownership, support contacts, admin procedures, known issues, deferred backlog, data-quality controls, release/change process, training materials, KPI definitions, and governance calendar.

## Hypercare Exit
Stable adoption; no Sev-1; Sev-2 controlled; ticket volume trending down; data-quality thresholds sustained; system owner accepts operational responsibility.
