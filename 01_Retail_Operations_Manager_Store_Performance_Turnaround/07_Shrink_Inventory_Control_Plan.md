# Shrink & Inventory Control Plan

## Objective
Reduce modeled shrink from 3.8% to 2.6% or better through repeatable operational controls.

## Control Framework
**Prevent:** receiving verification, controlled access, role clarity.
**Detect:** weekly high-risk SKU cycle counts, variance thresholds, adjustment review.
**Correct:** root-cause analysis, recount, receiving investigation, process retraining.
**Escalate:** repeated or material unexplained variance to Store Manager.

## Cycle Count Procedure
1. Generate high-risk SKU list.
2. Freeze/record expected quantity.
3. Conduct independent physical count.
4. Compare expected vs actual.
5. Recount material variances.
6. Categorize cause.
7. Assign corrective action.
8. Retain count evidence.

## Threshold
Variance above 1.5% for monitored items requires documented investigation.

## Reporting
Weekly shrink trend, number of exceptions, repeat exceptions, unresolved aged exceptions and top departments/categories by variance.
