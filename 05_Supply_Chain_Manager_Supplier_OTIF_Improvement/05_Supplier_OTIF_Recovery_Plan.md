# Supplier OTIF Recovery Plan

## Recovery Sequence
Contain immediate risk → validate backlog/commit dates → establish recovery schedule → correct root cause → verify performance → close action only after sustained evidence.

## Supplier Commitments
Confirmed production plan, shipment dates, quantities, capacity constraints, recovery milestones, owner, and evidence.

## Internal Actions
PO accuracy, forecast visibility, lead-time parameters, receiving readiness, inventory buffers, logistics coordination, and escalation.

## Exit
Supplier meets agreed OTIF threshold for the sustained validation period with no uncontrolled critical issue.
