# Supply Chain Management — Supplier OTIF Improvement

A corporate-style simulated supplier-performance transformation focused on On-Time In-Full (OTIF), lead-time reliability, fill rate, quality, inventory continuity, supplier governance, corrective action, and sustained performance management.

## Business Scenario
Supplier performance is inconsistent across critical categories. Late and incomplete deliveries create production/service risk, expedite cost, inventory instability, planner workload, and weak confidence in supplier commitments.

## Target Outcomes
- Supplier OTIF: 76% → >= 94%
- On-Time Delivery: 82% → >= 95%
- In-Full Delivery: 88% → >= 97%
- Average lead-time variance: 4.8 days → <= 1.5 days
- Supplier defect rate: 3.6% → <= 1.5%
- Expedite cost: $84K/month → <= $30K/month
- Critical material stockout incidents: 12/month → <= 3/month
- Supplier corrective-action closure on time: 58% → >= 92%

## Management Method
Measure → Segment → Diagnose → Contain → Correct → Collaborate → Verify → Standardize → Sustain.

## Work Products
Executive brief, charter, supplier segmentation, root-cause analysis, OTIF recovery plan, supplier scorecard framework, corrective-action process, inventory/continuity plan, S&OP/procurement governance, escalation model, weekly business review, sustainment plan, data dictionary, decision log, modeled source data, and a formula-driven supply-chain operating workbook.

> All suppliers, spend, costs, incidents, and performance results are simulated/modelled.
